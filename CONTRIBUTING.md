# Contribuindo com o Projeto CEA

## Como contribuir
- Crie uma branch para sua modificação
- Faça commits claros e objetivos
- Abra um Pull Request

## Padrões
- HTML semântico
- CSS organizado
- Nomes de arquivos em minúsculo

## Comunicação
Utilize as Issues para sugerir melhorias ou relatar problemas.
